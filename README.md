# FramStayAIVideo

Short AI drone-style preview videos for villas and farm stays in India,
used to pitch owners a full cinematic video.

- [`docs/research/video-models.md`](docs/research/video-models.md): which
  image-to-video models to test, with prices (October 2026).
- [`bakeoff/`](bakeoff/README.md): the pack for comparing those models on real
  properties before building the pipeline.

Run the tests with `uv run --group dev pytest`.
